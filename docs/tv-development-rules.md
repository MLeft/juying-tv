# 聚影 TV 开发与设计规范

> 版本 1.0 · 2026-11-08
> 适用对象：本项目所有开发者与 AI Agent。
> 本文件是强制规则，不是建议清单。`AGENTS.md` 是入口，冲突时以本文件为准。
>
> 关键词：**必须（MUST）**、**禁止（MUST NOT）**、**应当（SHOULD）**、**可以（MAY）**。
> 每条规则都来自真实踩坑，末尾「复盘」记录了反例来源。

---

## 0. 三条产品原则

1. **遥控器优先**：所有功能必须只用 D-pad（上下左右、确认、返回）完成，不依赖触摸、鼠标、悬停、长按或滑动。
2. **缩略图优先**：目标用户包含 4 岁儿童，能看图就不靠读字；选集、卡片、进度定位都必须有画面。
3. **宁可缺失，不可错误**：封面、标题、字幕匹配不确定时，回退到安全占位，绝不展示张冠李戴的内容。

设计基调：暗色影院 + 暖金强调；信息克制、层级清晰、动效短促；同一类控件在全应用保持同一规格。

## 1. 十二条红线

| ID | 规则 | 违反后果 |
| --- | --- | --- |
| R01 | 新功能必须纯 D-pad 可达，且任何状态下焦点都不能丢失 | 直接返工 |
| R02 | 焦点修饰符顺序错误（把 `onFocusChanged` / `onPreviewKeyEvent` 放在 `focusable()` 之后）视为缺陷 | 焦点/按键静默失效 |
| R03 | 禁止在列表或页面中段设置 `down = FocusRequester.Cancel` | 后续新增板块永久进不去 |
| R04 | 选中态与聚焦态必须是两种不同视觉，不能共用同一个高亮 | 用户误判光标位置 |
| R05 | 面板宽度、圆角、底色、标题样式必须复用既有规格，不得随意加宽 | 破坏整体审美 |
| R06 | 选项文字必须真正水平居中；聚焦/选中不能改变文字位置和行高 | 视觉廉价、跳动 |
| R07 | 可聚焦控件必须有明确焦点态，且不能只靠颜色区分 | 弱视/远距离不可辨 |
| R08 | 播放器控制栏自动隐藏不得抢走焦点；聚焦中控件时暂停倒计时 | 操作被打断 |
| R09 | 儿童内容必须用缩略图卡片；禁止用首字母/首字做封面 | 孩子无法识别 |
| R10 | 封面、元数据不确定时宁缺勿错；发现错误封面立即清除 | 错误信息比没有更糟 |
| R11 | 每次可安装改动必须真机安装并截图验证；编译通过不等于完成 | 不得宣称已完成 |
| R12 | 升级只允许 `adb install -r`；每次装机 `versionCode + 1`；禁止卸载重装 | 丢失媒体库/Cookie |

## 3. 焦点系统（最高风险区）

### 3.1 修饰符顺序（硬规则）

`focusRequester`、`onFocusChanged`、`onPreviewKeyEvent` 都是焦点节点的**外层**修饰符，必须写在 `focusable()` / `clickable()` **之前**：

```kotlin
// 正确
Modifier
    .onFocusChanged { focused = it.isFocused }
    .onPreviewKeyEvent { event -> /* 处理按键 */ false }
    .focusRequester(requester)
    .focusable()

// 错误：焦点能进去，但状态不更新、按键收不到，表现为“功能没生效”
Modifier
    .focusable()
    .onFocusChanged { focused = it.isFocused }
```

- **MUST** 新增可聚焦控件时先检查顺序；焦点“不亮”“按键无反应”首先排查这里。
- **MUST** 面板打开后 100ms 左右主动 `requestFocus()` 到第一个可操作项，避免焦点停在根节点。
- **MUST** 关闭面板/弹窗/对话框后，把焦点还给触发它的控件（如字幕按钮），不能失焦。
- **SHOULD** 用 `onPreviewKeyEvent` 拦截属于本控件的方向键（如进度条左右 ±5 秒），并返回 `true` 防止事件再去触发全局逻辑。

### 3.2 分区导航

- 左侧导航与内容区是两个区域：**上下键只在当前区域内移动，左右键跨区**。
- 导航栏右键必须能回到“当前可见内容”的第一个可操作项；导航选中项滚出屏幕时，必须有几何搜索或显式 `FocusRequester` 兜底，禁止卡死。
- 详情页显式串联焦点链：返回 → AI/刮削/编辑 → 播放 → 季 → 剧集，避免方向键随机跳转。
- 页面级恢复使用 `FocusCoordinator` / `SaveableStateHolder` 保存每个界面的焦点和滚动位置。

### 3.3 焦点边界

- 边界只加在**真正的第一个/最后一个**可操作项。
- **禁止**在中间行写 `down = FocusRequester.Cancel`；这会在新增板块时形成永久断路。
- 列表最后一行的越界拦截用按键守卫：

```kotlin
Modifier.onPreviewKeyEvent { e ->
    if (e.type == KeyEventType.KeyDown &&
        e.nativeKeyEvent.keyCode == KeyEvent.KEYCODE_DPAD_DOWN
    ) true else false
}
```

- 设置类长列表优先用 `Column + verticalScroll`；`TvLazyColumn` 在滚动到中后段后可能出现上下键整体失灵，必须使用时要在真机验证首项、末项和滚动后三段。

### 3.4 弹窗、PIN 与对话框

- PIN 键盘、手机扫码弹窗、确认弹窗必须有明确的首焦点，禁止“只能看不能选”。
- 对话框默认吃焦点；取消/确认按钮都要可聚焦，返回键先关弹窗再退页面。
- 返回键处理顺序固定：子面板 → 父面板 → 控制栏 → 页面退出；不允许越级退出。

### 3.5 选中态 ≠ 聚焦态

- 导航选中：金色图标/文字 + 左侧 4dp 金色短条，背景透明、无边框。
- 导航聚焦：胶囊底色 + 金色描边。
- 内容卡片选中：金色描边 + 小角标；内容卡片聚焦：放大 + 外发光 + 描边。
- **MUST NOT** 给“选中但未聚焦”的项加与焦点相同的高亮边框，否则用户会误以为光标在那里。

### 3.6 自动隐藏与焦点

- 播放器控制栏只在“正在播放、无面板、焦点不在控制条上”时启动 6 秒隐藏倒计时。
- 任意按键都重置倒计时；焦点停留在进度条等控件上时**暂停**倒计时。
- 控制栏隐藏后，D-pad 左右是快进/快退 10 秒并显示 HUD，确认/上下先唤出控制栏。

### 3.7 焦点排查法

1. 先用 `adb shell input keyevent KEYCODE_DPAD_*` 走一遍完整链路，每步截图确认焦点位置。
2. 不要盲按后凭猜判断；截图里的焦点描边/高亮是唯一可靠依据。
3. 检查修饰符顺序、`focusProperties` 是否在中段断路、列表是否用了 TvLazy。
4. 面板关闭后焦点是否回到触发控件。

## 4. 视觉设计系统

### 4.1 色板（唯一来源：`JuyingColors`）

| Token | 值 | 用途 |
| --- | --- | --- |
| Background | `#070B12` | 页面底色 |
| BackgroundAlt | `#0B1220` | 次级背景 |
| Surface | `#111C2E` | 卡片/面板 |
| SurfaceHigh | `#1A283C` | 次级按钮/标签 |
| SurfaceFocused | `#2B2418` | 焦点暖底（全应用统一） |
| Outline | `#263B55` | 默认描边 |
| Gold | `#E7B563` | 强调、选中、进度 |
| GoldBright | `#FFD48C` | 主按钮焦点 |
| OnGold | `#201503` | 金色上的文字 |
| TextPrimary | `#F4F7FB` | 主文字 |
| TextSecondary | `#9FB0C7` | 次文字 |
| TextMuted | `#6E8099` | 说明文字（不小于 11sp） |
| Blue | `#6FB7FF` | 信息徽标 |
| Red | `#FF6B6B` | 错误/删除 |
| Green | `#63D6A3` | 完成 |
| KidsAccent | `#7EE0C2` | 儿童模式 |

- 播放器二级面板统一使用 `#F0101A28` 深色半透明底 + `Outline` 85% 描边。
- **MUST** 使用主题 token，禁止在业务代码里新造近似色；确需新色先加 token 并同步本表。
- 正文与背景对比要足够；`TextMuted` 只用于说明，不用于关键操作。

### 4.2 字号与字重

| 场景 | 规格 |
| --- | --- |
| 页面主标题 | `headlineLarge` 34sp Bold |
| 区块标题 | `headlineMedium` 28sp SemiBold |
| 卡片标题 | `bodyMedium` 16sp，最多 2 行 |
| 按钮/选项 | `labelLarge` 17sp SemiBold |
| 说明文字 | `bodySmall` 14sp / 最小 11sp |
| 时间码 | `bodySmall`，等宽感对齐，固定宽度 64dp |

- **MUST NOT** 为了塞下长标题把字号压到 14sp 以下；优先缩短文案、换行或调整布局。
- 标题必须保留系列身份：先品牌/季别，再具体内容；禁止只写“4分钟以上”“完整版外挂”这类无主语短词。

### 4.3 间距、圆角、安全区

- 页面左右 36dp，上下 18–22dp；区块间距 14–18dp；元素间距 8–12dp。
- 卡片圆角 16dp；面板圆角 18dp（字幕样式预览面板为历史遗留 22dp，不再扩散）；按钮/胶囊全圆角；焦点描边 2dp。
- 主焦点缩放：卡片 1.04，按钮 1.05，紧凑菜单行 1.012；禁止大幅缩放导致相邻元素重叠。
- 焦点阴影 18dp，仅在聚焦时出现。

#### 焦点视觉四件套（必须同时具备）

1. **暖色底**：`SurfaceFocused #2B2418`，与金色描边同色系。
2. **2dp 金色描边**：`Gold #E7B563`；危险操作使用 `Red`。
3. **边缘泛光**：使用共享修饰符 `Modifier.focusGlow(...)` 画双层暖金描边（外扩 1.5/4.5dp，透明度 0.55/0.20），并叠加 `GoldBright #FFD48C` 彩色阴影，150ms 渐入渐出。
4. **缩放**：按控件类型取 1.012–1.09，spring 过渡。

选中态只保留平面标记（金色文字、圆点、勾选、左侧短条），**不得使用泛光、缩放或 2dp 金边**；泛光与描边是焦点的专属签名。

### 4.4 面板规格（新增面板必须复用）

| 类型 | 宽度 | 位置/说明 |
| --- | --- | --- |
| 二级菜单（字幕/倍速/画面/画质） | 340–360dp | 右下，距右 36dp、距底 120dp |
| 选集侧栏 | 510dp | 右侧全高，两列缩略图 |
| 搜索/设置对话框 | 620–760dp | 居中，内容区独立滚动，底栏固定 |
| 字幕样式（带实时预览） | 860dp（唯一的宽面板例外） | 右下；含预览与分段选项，不得再新增同类宽度 |
| 定位预览 HUD | 620dp | 底部居中，控制栏上方 |
| 错误/空状态 | 560dp | 居中 |

- **MUST** 同类面板同宽同圆角同标题样式；信息多时改为分组卡片或两列网格，不是把面板拉宽。
- **MUST NOT** 新建 500dp 以上的“纯列表”面板；超过 760dp 只允许用于媒体预览类内容。
- 面板内选项行高 44–48dp，通栏、文字居中、选中右侧金点；聚焦底色用暖金深色（`#2A2418`），不用蓝色。

### 4.5 水平居中

选项文字必须真正居中，且在聚焦/选中/文字变粗时不发生位移：

```kotlin
Box(Modifier.fillMaxWidth(), contentAlignment = Alignment.Center) {
    Text(
        text,
        modifier = Modifier.fillMaxWidth(),
        textAlign = TextAlign.Center,
        maxLines = 1
    )
}
```

- 分段选项（如字幕字体/大小）必须等宽；用 `weight(1f)` 而不是内容自适应，避免选中后宽度跳动。
- **MUST** 真机截图检查居中，不能只看代码。

### 4.6 卡片与缩略图

- 剧集/内容卡片统一 16:9；媒体库 4 列；首页横向卡片可更大。
- 卡片必须包含：缩略图、集数/季别角标、可读标题；当前集用金色边框和“播放中”标识。
- 选集面板必须是两列缩略图卡片，不允许退化为纯文字列表。
- 缩略图缺失时用同系列首集缩略图，再退到渐变占位；禁止文字字母占位。

### 4.7 封面规则

优先级：
1. 已核验的官方海报（TMDB 等）；
2. 该系列第一集视频帧；
3. 中性渐变占位。

- **MUST NOT** 用剧名首字、首字母生成封面。
- 发现封面张冠李戴（如多部剧共用同一张人像）时立即清空，不要“先留着”。
- 网络图源限流或不可达时记录缺口，不要伪造成功。

### 4.8 文案

- 面向儿童和家长，语气简短、可执行；按钮用动词（“从第一集开始”“继续观看”）。
- 标题压缩规则：品牌/季别在前，具体集题在后；保留区分词；示例 `S1内嵌 字母积木`、`01 初唐诗坛`、`完整版 外挂`。
- 错误文案要说明原因和下一步，禁止只显示“失败”。

## 5. 动效与反馈

| 场景 | 时长/规格 |
| --- | --- |
| 焦点缩放/阴影 | spring，damping 0.72 / stiffness 560 |
| 焦点描边/底色 | tween 150ms |
| 焦点泛光 | tween 150ms 渐入渐出 |
| 面板进出 | fade 120–160ms + slide 140–180ms |
| 页面切换 | 淡入 + 轻微位移 180ms |
| 骨架屏脉冲 | 900–1200ms 循环，低对比 |
| Toast | 入场 160–180ms，停留 2.4s |
| 定位 HUD | 停留 1.8s，随后淡出 |
| 进度条聚焦加粗 | 3dp → 7dp，160ms |

- **MUST** 所有状态变化都有反馈：加载、空、错误、成功、处理中。
- 长任务（扫描、刮削、AI）必须有持续进度与阶段文案，完成后保留明确结果；不能只给 3 秒 toast。
- 动效服务于理解，不做无意义的旋转/弹跳；不得让动画阻塞焦点操作。
- 页面切换保留滚动位置、Tab、搜索词与筛选条件；返回后不能回到顶部。

## 6. 播放器规范

### 6.1 控制栏

固定顺序（从左到右）：选集、上一集、后退 10 秒、播放/暂停（大按钮）、前进 10 秒、下一集、字幕、倍速、画质、画面。

- 大按钮直径明显大于其他按钮；默认焦点在播放/暂停。
- 面板打开时控制栏保持可见，避免关闭面板后失焦。
- 播放结束自动下一集；最后一集停在结束态并提供重播/返回。

### 6.2 进度条与定位

- 进度条可聚焦；聚焦时加粗到 7dp、显示播放头、当前时间变金色，整行淡金底。
- 聚焦后左右键 ±5 秒精细定位；控制栏隐藏时左右键 ±10 秒；两者都要显示定位 HUD。
- HUD 包含：目标画面帧（提取失败回退集缩略图）、方向文案、`当前 / 总时长`、进度线。
- 帧提取做 5 秒桶缓存与并发限制；禁止在主线程解码。

### 6.3 画质面板

- 340–360dp，信息用 2×2 分组卡片：分辨率、帧率、编码、码率；下面是清晰度选项（自动 + 可选档位）。
- 单码率文件明确提示“只能播放原画”，不要给无效选项。
- 切换清晰度通过 Media3 `trackSelectionParameters` 限制最大分辨率/码率；切换后保持播放位置。

### 6.4 字幕

- 字幕、倍速、画面等二级菜单选项必须水平居中、通栏、同一焦点样式。
- 关闭任意字幕子面板后，焦点回到“字幕”控件。
- 在线搜索默认用当前**单集标题**，系列名只作为宽松兜底；输入框光标置尾，不自动弹键盘。
- 本地字幕入口必须用应用内文件浏览器（Download/Movies/Documents/U 盘），不能依赖系统 DocumentsUI。

### 6.5 性能

- 播放位置轮询仅在“控制栏可见或正在播放”时进行。
- 选集面板缩略图按需加载、限制并发、内存 LRU；不要一次性解码整季。
- 播放器状态（倍速、字幕样式、画面比例）退出后保留。

## 7. 媒体库、命名与合集

- 扫描后先归集为“剧集/电影”，不按原始目录平铺。
- 合集创建必须支持按媒体源**原始目录树**浏览并批量加入；自动分组只能作为建议。
- 合集内顺序、是否上首页、儿童可见范围都要可编辑。
- 儿童模式：家长可全选可见剧集；退出/进入需要 PIN；PIN 弹窗必须可操作。
- 扫描/整理要显示数量与阶段（如“正在整理 3/7”），完成后刷新媒体库。
- 标题、封面、集数、季别是同一套元数据，任何整理工具（内置或 MCP）都必须保持三者一致。

---

## 8. 字幕链路

1. 优先扫描视频同目录的 `.srt/.ass/.ssa/.vtt`，按文件名/集数匹配。
2. 检测 GBK/Big5 等编码并转 UTF-8；ASS 样式尽量保留可读性。
3. 在线源（OpenSubtitles 旧版 REST）只作为补充；已知大量儿童英语内容覆盖不足，不要承诺“全能搜到”。
4. 字幕字体、字号、位置、颜色要可调，预览实时更新；所有选项居中、等宽。
5. 字幕默认居中；改动样式后焦点回到字幕控件，不回到播放按钮。
6. 匹配不确定时提示用户手动选择，不要静默加载错集字幕。

---

## 9. 数据源、网络与 MCP

### 9.1 夸克网盘

- 非官方接口：Cookie 会过期；`412/31001/23018` 等错误要给出可操作提示。
- 大目录禁止直接递归全盘；先列目录、让用户多选根路径，避免“目录文件过多”。
- 预览图/缩略图接口返回的不一定是视频流，播放地址必须单独解析并校验。
- Cookie 只显示“已填写 · N 字符”，编辑放在固定高度弹窗；支持手机扫码填写。

### 9.2 WebDAV / 本地

- 支持 Basic 认证、Range 播放、递归扫描、外挂字幕。
- HTTP 明文仅限家庭局域网；UI 要有安全提示。
- 系统级 SAF 目录选择在部分电视固件不可用，必须有替代路径（MediaStore/U 盘/WebDAV）。

### 9.3 TMDB / 刮削

- 网络受限时优先直连 API 与图片 CDN；记录限流并降级，不阻塞主流程。
- 刮削结果必须可人工编辑、可撤销；自动匹配低置信度时不写入。
- 海报找不到就留空并记录，不编造。

### 9.4 MCP

- MCP 是外部 Agent 的操作面：工具契约要稳定、字段自解释、错误可读。
- 批量查询禁止 N+1；一次聚合返回剧集、集数、路径、封面等所需字段。
- 只监听局域网，使用 Bearer Token；不在日志中输出 Token/Cookie。
- 媒体库整理由外部 Agent 用其自身模型完成；应用内置 AI 不作为默认整理通道。

## 10. AI 能力

- 供应商必须可插拔（OpenAI 兼容协议），支持自定义 Base URL、模型名与 Key；禁止写死单一厂商。
- 长响应使用流式 + 分块；设置超时、重试与取消；UI 显示阶段进度。
- AI 输出必须经过校验（JSON 结构、剧集边界、标题长度）后再落库。
- AI 结果可撤销、可重试；失败时保留原数据。
- API Key 只存本机，不写日志、不上传。

## 11. 性能预算与实践

| 项 | 规则 |
| --- | --- |
| 列表 | 大数据用 Lazy 布局；避免每帧重建；为 item 提供稳定 key |
| 缩略图 | 解码限并发（建议 2）；缩放目标约 480×270；内存 LRU + 负缓存 |
| 磁盘缓存 | Coil 约 160MB；缩略图缓存定期清理（集缩略图 200MB、定位帧 60MB） |
| 内存 | 图片用 RGB565；关闭不必要的 crossfade |
| 查询 | 禁止 N+1；合集聚合一次查完；避免 O(n²) 嵌套遍历 |
| 轮询 | 播放器位置轮询按可见性开关；页面不可见停止 |
| 启动 | 缓存清理放后台；不要阻塞首屏 |

- **MUST** 在真机上验证滚动帧率与大库首屏时间；模拟器数据不作为依据。
- 新增大列表前先问：是否可以用分页/聚合/缓存避免全量计算。

## 12. 构建、签名、装机与发布

### 12.1 构建

```bash
export JAVA_HOME=~/android-jdk/Contents/Home
export ANDROID_HOME=~/android-sdk
~/gradle-dist/gradle-8.7/bin/gradle -p /Users/hugh/code/wangzai assembleRelease testReleaseUnitTest
```

- JDK 路径是 `~/android-jdk/Contents/Home`，不是 `~/android-jdk`。
- 产物：`app/build/outputs/apk/release/app-release-unsigned.apk`。

### 12.2 签名

```bash
JAVA_HOME=~/android-jdk/Contents/Home \
~/android-sdk/build-tools/34.0.0/apksigner sign \
  --ks release/juying-release.jks --ks-key-alias juying \
  --ks-pass pass:<storepass> --key-pass pass:<keypass> \
  --out dist/JuyingTV-<version>.apk dist/JuyingTV-<version>.apk
```

- 密钥 `release/juying-release.jks`，密码在 `release/keystore-info.txt`，不写进仓库正文。
- 签名必须与应用历史一致，否则无法覆盖安装。

### 12.3 装机

```bash
ADB_USB=0 ~/ptools33/platform-tools/adb connect 192.168.1.196:5555
ADB_USB=0 ~/ptools33/platform-tools/adb install -r dist/JuyingTV-<version>.apk
ADB_USB=0 ~/ptools33/platform-tools/adb shell am force-stop com.juying.tv
ADB_USB=0 ~/ptools33/platform-tools/adb shell am start -n com.juying.tv/.MainActivity
ADB_USB=0 ~/ptools33/platform-tools/adb shell dumpsys package com.juying.tv | grep version
```

- 每次装机 `versionCode + 1`、`versionName` 同步更新；禁止卸载（会丢媒体库、合集、Cookie、观看进度）。
- 版本号界面显示必须读取 `BuildConfig.VERSION_NAME`，禁止硬编码。
- 升级后用截图确认媒体库数量与进度仍在。

### 12.4 验证与提交

- 必须验证：首页、媒体库、详情、播放、控制栏、进度条、画质/字幕/倍速/画面面板、返回焦点。
- 截图保存关键状态；焦点类改动至少截“聚焦前/聚焦后”两张。
- 更新 README 中的 APK 版本号与已知限制，禁止文档落后于代码。
- 单元测试与 release 构建全绿后再 commit；无远端时只本地提交，不假装已推送。
- 提交信息说明“为什么”，不只写“改了什么”。

## 15. 复盘：做得好与做得不好

### 15.1 做得好的

1. **能力边界清晰**：把媒体库整理外置为 MCP 工具，由外部 Agent 用自己的模型完成；内置 AI 只做辅助，避免了写死厂商和长任务超时。
2. **缩略图体系**：首集帧兜底、选集缩略图、定位帧预览、并发限制与多级缓存，真正贴合儿童用户。
3. **焦点分区与视觉区分**：导航选中/聚焦分离、详情页显式焦点链、面板关闭回焦，显著减少“光标在哪”的困惑。
4. **性能治理成体系**：修 N+1、O(n²)、播放轮询、合集路径聚合、缓存清理，而不是零散打补丁。
5. **版本链与数据安全**：每次装机递增版本、只覆盖安装、升级后验证媒体库与进度仍在。
6. **诚实记录限制**：字幕源覆盖、海报缺口、夸克非官方接口都写进文档，没有包装成“全支持”。
7. **组件复用**：`FocusableSurface`、`TvChip`、`TvButton`、统一的色板/字号/圆角，是后续一致性的基础。

### 15.2 做得不好的

1. **修饰符顺序错误**：进度条“看起来实现了”，实际聚焦态和按键都没生效；这类问题编译期无法发现，只能靠真机截图。
2. **面板审美返工**：画质面板首版 500dp，信息横排、右侧大片空白；用户直接指出“太宽、注意审美”。
3. **文字居中靠猜**：胶囊选项曾未真正水平居中，且聚焦后字重变化导致位置抖动。
4. **标题压缩过度**：早期把系列名压成“4分钟以上”“完整版外挂”，丢失识别信息。
5. **首字封面**：用首字母做占位对 4 岁儿童无效，后来才改为首集缩略图。
6. **自动隐藏与焦点打架**：控制栏在用户操作进度条时消失，焦点被踢回根节点。
7. **盲按键验收**：用 adb 连续按键后凭猜判断界面状态，效率低且容易误判；应每步截图。
8. **文档滞后**：README 版本号长期停在 1.5.3，功能限制描述与实现脱节。
9. **中段焦点锁**：`down = Cancel` 曾挡住后续新增的 AI 板块，属于结构性隐患。
10. **未先验证外部依赖**：字幕源、海报源在接入前没有充分验证覆盖率，导致返工与预期落差。

### 15.3 沉淀出的三条方法论

1. **状态优先于代码**：任何交互改动，以真机截图中的焦点、选中、进度为准，不以“代码写了”或“编译过了”为准。
2. **规格优先于灵感**：新面板、新控件先从规格表里选类型；没有对应类型时，先补规格再实现。
3. **可回退优先于一次到位**：封面、元数据、AI 结果、字幕匹配都要有安全回退；错误展示比缺失更有害。
